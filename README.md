# 🩺 Medi-Scan AI

### Multi-Disease Prediction & Health Assessment Dashboard

Medi-Scan AI is an AI-powered machine-learning application designed to demonstrate predictive analysis for multiple health conditions through an interactive Streamlit dashboard.

The application currently supports:

- 🩸 Diabetes Prediction
- 🧬 Anemia Prediction
- 🦋 Thyroid Condition Prediction

The project combines trained machine-learning models with a modern, user-friendly dashboard to provide prediction results based on user-provided medical parameters.

> ⚠️ **Disclaimer:** This project is intended for educational, research, and demonstration purposes only. The predictions generated by the application are not medical diagnoses and should not replace advice from a qualified healthcare professional.

### 🩸 Diabetes Assessment

The diabetes model uses features such as:

- Pregnancies
- Glucose
- Blood Pressure
- Skin Thickness
- Insulin
- BMI
- Diabetes Pedigree Function
- Age

The application returns:

- Model-predicted risk
- Prediction status
- Model probability

# 🧠 Machine Learning Models

The application uses pre-trained machine-learning models.

| Disease | Model | Supporting Artifact |
|---|---|---|
| Diabetes | XGBoost | StandardScaler |
| Anemia | LightGBM | StandardScaler |
| Thyroid | XGBoost | StandardScaler + Target Encoder |

Models are stored using `joblib` serialized `.pkl` files.
